# v2.0.0-rc.2 · 小红书 AI 发布助手改版预发布

2026-10-15。本版整合 `v1.2.0` 之后的本地改版，供提前试用和验收；稳定版仍为 `v1.2.0`。程序包在各平台构建及打包检查成功后上传到此 Release，源码归档可直接下载。

## rc.2 修复

`rc.1` 的远端 191 项回归测试通过，但启动冒烟检查发现日志仍尝试写入不存在的 Desktop 目录，安装包构建因此被阻止。本版统一日志路径到应用数据目录，并新增无 Desktop 依赖的子进程启动检查。压缩包只包含可运行的程序目录，排除编译中间文件。`rc.1` 标签保留，试用请使用本版。

## 本次更新

- **中文写稿与润色**：按提供的素材组织正文，新增独立中文二次审稿和个人语气参考；模型不可用时只预览原文。润色可能增加一次模型请求，校验失败时最多再试一次。
- **封面中心与 13 款精选模板**：新增橙白立体、奶油杂志、柠檬清单、薄荷纸雕、大截图图文。精简相似模板，旧稿和自定义模板保留兼容入口。
- **多页图文**：封面图和正文配图可以分别选择；正文配图可排序、留空，长文继续分页，截图保持完整比例，续页不重复图片。
- **发布流程修复**：发布排队和重复提交拦截；排队期间改稿、图片失效或切换登录会话会停止任务。发布按钮只尝试一次，区分已提交、审核中和待核验；失败或重启中断后暂停，不自动重发。
- **Web 访问保护**：默认监听 `127.0.0.1`，Docker 宿主端口默认绑定本机。远程调用必须配置 `XHS_WEB_API_TOKEN`，通过 HTTPS 发送 `Authorization: Bearer <token>`。配置令牌后所有 API 调用都需要认证，Web 页可输入令牌。反向代理或隧道同样必须配置令牌；跨来源浏览器 API 请求默认拒绝。
- **发布与数据目录**：桌面端、API 和版本文档统一版本号；密钥和日志遵守 `XHS_DATA_DIR`，默认位置不变。测试使用临时目录，不删除用户密钥。新增打包前回归检查，以及安装包字体、规则文件和模板渲染检查。

## 验证范围与已知问题

- 本地维护中的离线回归测试：**192 项通过**，命令为 `python scripts/test_release.py`，覆盖文案、排版、发布保护、访问控制和 Mac 启动逻辑。
- 源码冒烟检查：`python main.py --smoke-test` 通过，读取 13 款模板，并实际渲染 5 种新增版式的封面和正文页；不登录、不发布、不调用模型。
- 完整非浏览器测试：**238 项通过、17 项失败、10 项浏览器测试未运行**。失败分布为旧封面测试 13 项、用户管理 3 项、Kimi 提示词断言 1 项；包含退休接口引用、共享测试数据及指纹模型字段不一致。发布门槛仅针对上面的维护中离线套件，不代表全量测试通过。
- 各平台安装包由 GitHub Actions 构建并检查，成功后才上传；本地源码测试不能代替 Windows、macOS 和 Linux 的完整桌面验收。macOS 程序未做 Apple 公证。
- 真实账号的完整登录、审核及发布流程仍需实机验收。Web 页面仍有待整理的旧接口流程；建议以桌面端写稿、做图为主，Web/API 用户按当前 API 文档操作。
- 发布队列只支持单 Web worker，暂不建议无人值守连续发布。提交成功不等于平台审核通过；生成内容、账号、图片与 AI 声明需自行核对。

## 升级

升级前退出旧程序，并备份 `~/.xhs_system/`（自定义数据目录则备份该目录）。保留该目录后替换程序，原配置和稿件不主动清空。旧模板会映射到相近的保留模板。若此前设过 `XHS_DATA_DIR`，密钥与日志现在也跟随该目录；如需沿用默认目录中的密钥，请在新版中重新配置。

## English

RC.2 fixes startup on machines without a Desktop directory and adds a subprocess regression check. RC.1 remains tagged but its package build was blocked by the startup check.

This pre-release brings together the redesign since `v1.2.0`: Chinese second-pass editing and writing samples, 13 curated templates, ordered body images, uncropped screenshots, text overflow pagination, publication deduplication and pause-for-review behavior.

Web access defaults to loopback. Remote access requires `XHS_WEB_API_TOKEN` over HTTPS with Bearer authentication; configured tokens are required for local requests too. Set a token behind reverse proxies and tunnels. The Web page accepts a token in memory. Credentials and logs now honor `XHS_DATA_DIR`.

**Validation:** 192 maintained offline tests pass; source smoke checks load 13 templates and render five new layouts. The complete non-browser run has 238 passes and 17 failures, with 10 browser tests excluded. Failures remain in legacy cover tests (13), user management (3) and one Kimi prompt assertion. This is not a full-suite pass. Platform packages are uploaded only after their build and packaged smoke check succeed; real-account publication and full desktop acceptance remain unverified. The legacy Web page has unfinished endpoint flows. Use one Web worker and verify uncertain submissions before retrying.

Back up the application data directory and quit the old app before upgrading. Existing data is retained. This remains a pre-release; `v1.2.0` stays the latest stable release.
