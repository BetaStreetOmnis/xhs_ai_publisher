# v2.0.0-rc.3 · 候选安装包

2026-11-03。本版先用于用户验收，未公开发布。确认后再更新官网、默认分支和公开 Release；当前公开下载仍是 rc.2。

## 与 rc.2 的区别

- 定时发布改为本地提醒。到点不打开浏览器、不提交笔记；软件需要保持运行，休眠或退出期间不能提醒。
- 热点仅生成一次本地草稿，保存文字、图片和参考来源；不按旧间隔循环生成或发布。
- 发布前核对内容、素材与 AI 使用，再辅助填写页面；最终到小红书核对账号并由本人点击发布。桌面及本机 API 拒绝自动提交参数。
- 旧待执行任务使用提醒策略；执行中、已提交和审核中的记录仍需人工核验，不自动重发。
- 移除自动化属性隐藏脚本与强制 DOM 动作兜底。人工操作和 AI 声明不能保证平台审核通过。

## 安装与升级

先退出旧程序，备份 `~/.xhs_system/` 或自定义数据目录。解压候选包后启动；不需要先登录小红书或配置模型，就可以手动写稿和排版。模型写稿仍使用自己的模型账号。

Windows x64 使用 ZIP；macOS Apple Silicon / Intel 和 Linux x64 使用 tar.gz。macOS 未经 Apple 公证。Chromium 不随包提供；单纯写稿和排版不需要先安装浏览器。

## 验证范围

使用 `python scripts/test_release.py` 执行维护中的离线测试，并用 `python main.py --smoke-test` 检查版本、13 款模板及五种版式的实际渲染。各平台构建还需运行打包程序的 `--smoke-test`，通过后才能保留对应产物。

离线测试和打包冒烟不等于四个平台的完整桌面验收。真实小红书账号登录、辅助填写、审核及发布尚未在本次候选中验证。不据此承诺账号安全或发布成功。

## English

Review candidate only; not a public release. Scheduled publishing becomes a local reminder, hot topics produce one saved draft, and final submission requires the user on Xiaohongshu. Desktop and local API calls reject automatic submission. Existing uncertain submissions remain for review.

Quit the old app and back up the data directory before trying this build. Manual editing and layout do not require an account or model key. Model writing uses your own provider. macOS packages are not Apple-notarized; Chromium is not bundled.

Each platform must pass its packaged smoke check. These checks do not replace full desktop acceptance or real-account publication testing. Public downloads remain on rc.2 until approval.
